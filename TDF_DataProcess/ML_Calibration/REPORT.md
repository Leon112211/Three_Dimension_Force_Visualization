# 四方案标定对比实验报告

**线性矩阵基准 vs 二次多项式 vs 直接 MLP vs 残差学习(线性 + MLP 学残差)**

- 数据:`TDF_DataProcess/Raw_Data` 单轴分级加载标定数据(8 个传感器×轴组合,约 8.8 万帧,纯离线,不接硬件)
- 代码:[train_calibration.py](train_calibration.py) · 原始结果:[results/results.json](results/results.json) / [results.csv](results/results.csv)
- 实验日期:2026-07-24 · 分支:dev
- 可信度:实验设计经**独立对抗审查**(数据泄漏逐项核验通过),关键数字经**独立 numpy 复现**(偏差 0.05–0.7%)

---

## 一句话结论

**在力级数量充足(41 级)的 Z 轴上,小型 MLP 与残差学习把留出力级的力重建误差降到线性矩阵的 1/2 ~ 1/3(H2:0.49→0.17 N;H4:0.59→0.28 N,已逼近 0.24 N 的噪声底);在基本线性的 H6 上学习模型与二次拟合打平;在只有 7 个力级的 X/Y 轴上,MLP 没有优势、线性/二次反而更稳——非线性建模的收益同时取决于"非线性是否存在"与"标定数据是否足够"。**

## 1. 实验设置

| 项 | 设定 |
|---|---|
| 输入 → 输出 | ΔB(3 通道,逐帧 − 零力级均值)→ 施力轴力值 F (N) |
| 划分 | **严格按力级**:Z 轴 4 折交叉(内部级 idx%4 轮流留出),X/Y 留一力级;端点(0 N / 满量程)恒在训练集 → **只考察插值** |
| 训练帧 | 每级限采 200 帧(四模型共用同一训练集);测试帧全保留 |
| M1 线性 | 3 输入最小二乘(+截距)——矩阵解耦的单轴等价物 |
| M2 二次 | 标准化 → 2 阶多项式特征 → Ridge(α=1e-3,近似无正则) |
| M3 MLP | 3→16→16→1,ReLU,lbfgs(上限 3000 迭代),5 个随机种子 |
| M4 残差 | M1 + 同规格 MLP 学习线性残差,5 种子 |
| 指标 | 留出力级**逐帧 RMSE**(±折间/种子间分解);**单种子**最大级均值误差(均值/最差);%FS;噪声底(线性模型级内预测波动中位数) |

防泄漏要点(全部经对抗审查核验):基线只来自恒在训练集的零力级;StandardScaler 仅在训练集拟合;无任何在测试集上的调参;四模型同折同帧。

## 2. 主结果:Z 轴(41 力级,满量程 20 N)

| 组合 | 线性 | 二次 | **MLP** | **残差学习** | 噪声底 |
|---|---|---|---|---|---|
| **Z-H2**(全量程) | 0.489 N (2.45%) | 0.451 N | **0.167 N (0.83%)** | 0.178 N (0.89%) | 0.082 N |
| Z-H2(0–15 N,剔伪影) | 0.275 N | 0.284 N | **0.190 N** | 0.197 N | 0.100 N |
| **Z-H4** | 0.585 N (2.93%) | 0.338 N | **0.280 N (1.40%)** | 0.299 N (1.50%) | 0.239 N |
| **Z-H6** | 0.193 N | **0.128 N (0.64%)** | 0.150 N | 0.188 N | 0.106 N |

单种子最大级均值误差(均值 / 最差种子):

| 组合 | 线性 | MLP | 残差学习 |
|---|---|---|---|
| Z-H2 全量程 | 1.487 | 0.803 / **1.558** | 0.702 / **1.017** |
| Z-H4 | 1.322 | 0.485 / 0.517 | 0.484 / 0.520 |
| Z-H6 | 0.427 | 0.393 / 0.613 | 0.471 / 0.600 |

**解读:**

1. **H2(全量程)**:学习模型把 RMSE 砍掉 **66%**(0.489→0.167)。其中一部分收益来自 15→15.5 N 的夹具伪影(线性模型无法跨越的台阶,网络能拟合)——剔除伪影后线性降到 0.275,MLP 仍以 0.190 领先 **31%**,说明**真实非线性收益与伪影收益并存**;
2. **H4(真实平滑饱和非线性,灵敏度全程衰减 42%)**:教科书式结果——线性 0.585 → 二次 0.338 → MLP 0.280,MLP 已**逼近 0.239 N 的噪声底**,即剩余误差主要是测量噪声而非模型缺陷;最大级误差从 1.32 N 降到 0.52 N(最差种子口径,约 2.5 倍改善);
3. **H6(基本线性,R²=0.9991)**:二次略优(0.128),MLP 无优势——**方法没有在不需要的地方硬造收益**,这是结论可信的重要旁证;
4. **残差学习 vs 直接 MLP**:RMSE 几乎持平,但 H2 全量程上残差学习的**最差种子**明显更稳(1.02 vs 1.56 N)——物理模型兜底压住了坏种子的尾部风险,这正是"物理+学习"混合结构的价值所在。

## 3. 辅助结果:X/Y 轴(仅 7 力级,满量程 3 N)

| 组合 | 线性 | 二次 | MLP | 残差学习 | 最优 |
|---|---|---|---|---|---|
| X-H2 | **0.065** | 0.131 | 0.120 | 0.113 | 线性 |
| X-H4 | 0.055 | **0.039** | 0.100 | 0.048 | 二次 |
| X-H6 | 0.061 | 0.068 | 0.065 | 0.063 | 打平 |
| Y-H2 | 0.092 | 0.121 | 0.142 | **0.085** | 残差 |
| Y-H6 | 0.093 | **0.047** | 0.093 | 0.068 | 二次 |

**解读:** 5 个内部力级的留一验证下,MLP 全面没有优势(小数据过拟合),线性/二次占优;残差学习则**优雅退化**——最差也只比线性差一点,在 Y-H2 上甚至最优。X/Y 结果作为辅助性证据报告(统计力弱),但它与 Z 轴一起构成了本实验最有价值的完整结论:

> **非线性方法的收益 = 非线性强度 × 数据充分性。** 两者缺一,线性/低阶方法仍是正确选择。

## 5. 验证与可信度

- **对抗性代码审查**(独立智能体,含实际执行审计):泄漏项逐条核验通过(基线来源、Scaler 拟合域、折覆盖、无测试集调参、四模型同折同帧);裁定 SOUND_WITH_CAVEATS,其指出的"最大级误差种子集成美化"问题已在本版**修正**(改为单种子口径),误差棒口径已统一并标注,收敛警告不再静默(逐变体计数:X/Y 全 0,Z 轴 3–22 次,种子间波动 ≤0.08 N,不影响排序结论);
- **独立数值复现**(不复用本实验代码的 numpy 实现):Z-H4/Z-H6 的线性与二次 RMSE 复现偏差 0.05–0.7%,两条定性主张(H4 线性级误差在 3–6 N 区间超 1 N;H6 全程不超 0.5 N)均独立成立;
- results.json 保留每(折×种子)原始 RMSE 与每种子级预测,任何数字可回溯复核。

## 6. 与文献对标

- **Tomo et al., Sensors 2016**(霍尔式触觉传感单元,线性/二次/单隐层 NN 对比的最近前身):其结论为"二次总体最优、NN 只在法向力上赢"。本实验在 41 级数据上给出更细的分辨:**非线性强的传感器上 NN 明确胜出,线性传感器上二次即够**——并采用了其未使用的防泄漏留出协议与 %FS/牛顿单位指标;
- **Wang et al., Sensors 2016**(同款 MLX90393+磁铁嵌弹性体):同样放弃单一线性矩阵、改用高阶多项式标定,印证本架构的非线性是共性而非个例;
- **ReSkin (CoRL 2021)**:其单传感器 MLP 力 RMSE ≈0.07 N(量程小得多);本实验 Z 轴 0.17–0.28 N 对应 20 N 量程(0.8–1.4%FS),处于同一相对精度带。

## 7. 可直接用于申请材料的表述(全部有据可查)

- "Reformulated the calibration as a supervised learning problem and trained a lightweight MLP (≈1.3k parameters); on force levels held out from training, it reduced force-reconstruction RMSE by **52–66%** relative to the analytical sensitivity-matrix baseline on the two nonlinear sensors (0.59→0.28 N and 0.49→0.17 N on a 20 N range), approaching the measurement-noise floor."
- "On the intrinsically linear sensor the learned model showed **no advantage over a quadratic fit** — evidence that the method adds capacity only where the physics demands it."
- "With only 7 calibration levels (X/Y axes), the MLP overfits and the linear/residual formulations remain preferable — the benefit of learned calibration depends jointly on nonlinearity strength and calibration-data sufficiency."
- 残差学习的卖点句:"The physics-anchored residual formulation matched the direct MLP's RMSE while cutting the worst-seed maximum error from 1.56 N to 1.02 N — the analytical model bounds the network's failure modes."

## 8. 局限(报告/论文中必须如实声明)

1. **仅单轴静态加载**:结论限于单轴受力流形,不主张斜压/组合受力性能;
2. **插值口径**:端点(0 N/满量程)恒在训练集,所报误差不含外推;
3. 每力级仅一次加载会话:逐帧 RMSE 反映会话内噪声,不含日间重复性;无迟滞/动态信息;
4. X/Y 轴统计力弱(5 个留出点),仅作辅助证据;
5. Y-H4 缺原始数据(8 对而非 9 对);Y-H6 标定几何存疑(交叉响应大于主通道),其结果需谨慎引用;
6. Z 轴部分 MLP 拟合触及 lbfgs 迭代上限(已计数披露);种子间波动已单独报告,不改变方法排序。
